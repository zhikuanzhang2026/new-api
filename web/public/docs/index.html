一个 Key，接通 GPT、Claude、Grok、Seedance 与生图模型。统一 OpenAI 兼容接口，换模型不用换地址。

统一接口

基础地址：https://api.tokenni.com。所有模型均通过以下 OpenAI 兼容接口调用；更换同类型模型时，不需要更换接口路径。

用途方法路径
获取可用模型GET/v1/models
对话补全POST/v1/chat/completions
生成视频POST/v1/videos
查询视频任务GET/v1/videos/{id}
下载视频GET/v1/videos/{id}/content
生成图片POST/v1/images/generations
参考图编辑 / 图生图POST/v1/images/edits
统一的是接口，不是所有型号的能力。对话按 token 计费，视频按秒计费，图片按张计费；时长、分辨率、比例与参考素材数量仍按所选模型执行。视频是异步任务（先返回任务 ID，再轮询查询）；图片通常等待完成后直接返回 data[].url，不要用视频的轮询方式查图片。

认证与账户安全

本站 API 调用携带请求头 Authorization: Bearer sk-你的密钥。密钥在 控制台 · 令牌 创建。请只在自己的服务端保存密钥，不要写进网页、App 或公开代码仓库。

创建密钥时要选对分组：对话模型用 default / grok / claude 分组，视频用 see dance 分组，生图用 image 分组。分组不对会报 503 “没有可用渠道”，不是模型不存在。

新用户注册送 ¥0.5，每天签到再送 ¥0.05。余额不足时会报 401 / 403，先检查余额与密钥额度。

快速开始

下面是一个对话示例。把示例密钥换成自己的本站密钥。

curl -X POST "https://api.tokenni.com/v1/chat/completions" \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-6.2-sol",
    "messages": [
      {"role": "user", "content": "你好，介绍一下你自己"}
    ]
  }'

生成图片示例：

curl -X POST "https://api.tokenni.com/v1/images/generations" \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6-flare","prompt":"雨夜便利店，暖黄灯光，电影感写实","size":"1024x1024","n":1}'

生成视频示例（异步，保存返回的 id 再查询）：

curl -X POST "https://api.tokenni.com/v1/videos" \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "prompt": "雨夜便利店，暖黄灯光映在湿润街道上，固定镜头，电影感写实",
    "seconds": "5",
    "resolution": "720p"
  }'

对话：调用

POST /v1/chat/completions，OpenAI 兼容格式。支持流式（stream: true）与非流式。

{
  "model": "gpt-6.2-sol",
  "messages": [
    {"role": "system", "content": "你是一个有帮助的助手。"},
    {"role": "user", "content": "写一首关于雨天的短诗"}
  ],
  "temperature": 0.7,
  "stream": false
}

常用字段：model（完整模型 ID）、messages（对话历史）、temperature、max_tokens、stream。返回的 usage 里有本次消耗的 token 数，账单以实际 usage 为准。

Grok 的 prompt token 大部分会被缓存，实际扣费常比原始 prompt 长度低；Claude haiku / sonnet 请用 temperature: 1。

视频：提交、查询、下载

提交参数

POST /v1/videos，JSON。

字段说明
model视频模型的完整 ID，如 seedance-2.5。
prompt提示词；比例与分辨率应与所选参数一致。
seconds视频秒数，建议传字符串，如 "5"；必须用该型号支持的时长。
resolution清晰度，如 720p / 480p；固定清晰度的型号不要传其他档位。
aspect_ratio画面比例，如 16:9；建议显式传。

查询任务与统一状态

GET /v1/videos/{id}，使用提交时返回的本站任务 ID。

status含义处理
queued排队中继续查询
in_progress生成中继续查询
completed成功下载视频
failed失败读取 error，失败自动退款

建议至少间隔 30 秒查询一次。视频成功状态统一是 completed，不是 success 或 succeeded。

下载视频

GET /v1/videos/{id}/content，成功后下载，支持 Range。

curl -L -o result.mp4 "https://api.tokenni.com/v1/videos/task_xxxxxxxxxxxxxxxx/content" \
  -H "Authorization: Bearer sk-你的密钥"

下载用同一个本站密钥和原任务 ID，不创建新任务、不再次扣费。结果有时效，请尽快下载到自己的存储。

图片：生成与编辑

POST /v1/images/generations 生成图片。

curl -X POST "https://api.tokenni.com/v1/images/generations" \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"nano-banana-2.1","prompt":"雨夜便利店，暖黄灯光，电影感写实","size":"1024x1024","n":1}'

图片接口通常等待生成完成，成功后返回 data[].url。客户端应设置足够长的请求超时（建议 120 秒以上），收到结果后直接下载，不要用视频的轮询接口查图片。

返回示例：

{"created": 1763640000, "data": [{"url": "https://api.tokenni.com/..."}]}

POST /v1/images/edits 做参考图编辑 / 图生图，推荐用 multipart，字段与生成接口相同，另传 image（参考图文件）。通用建议：n=1；size、aspect_ratio 按模型说明填写。

计费、退款与重试

生成任务按所选模型的 token 数、秒数或张数收费；提交可能先预扣费用，任务完成后以使用日志的实际记录为准。失败的任务自动退款，不用手动申请。

提交超时或网络中断时不要自动重试 POST。这不代表任务没有创建。先查任务日志，收到 ID 后只查原任务；查询或下载超时也不要重新生成，避免重复扣费。

常见错误

情况检查方式
模型不存在 / 已停用确认完整 model ID、密钥分组与模型权限。
503 “没有可用渠道”多半是密钥分组不对：对话用 default / grok / claude，视频用 see dance，生图用 image。换对应分组的密钥再试。
比例或分辨率冲突提示词若写了 9:16，参数也应传 aspect_ratio=9:16；固定 720p 的型号不要传 1080p。
401 / 403检查 Bearer 密钥、余额、令牌额度及模型权限。
400 temperature 报错（Claude）haiku / sonnet 请把 temperature 设为 1。
429降低并发和轮询频率。
5xx / 提交超时先核实是否已创建任务，再决定下一步，避免重复扣费。
任务 / 下载不存在使用同一次提交返回的本站任务 ID；确认账号与任务类型。

常见问题

换一个模型要换接口吗？
不需要。同一类模型共用一个接口路径，换 model 字段就行；但要按新模型改时长、清晰度、比例等参数，并确认密钥分组对得上。

图片也用视频的查询接口吗？
不使用。图片接口通常直接返回 data[].url，按返回地址下载即可。

标准价和充值价有什么区别？
标准价是调用时从账户余额扣除的额度；充值价是实际支付的人民币。本站按 1 美元额度 = ¥7.3 结算，充值价 = 标准价 × 7.3。

注册有赠送吗？
有。注册送 ¥0.5，每天签到再送 ¥0.05，签到在个人中心完成。

失败会扣费吗？
不会。生成失败自动退款，以使用日志的实际记录为准。
